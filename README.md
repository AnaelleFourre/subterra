# Contrôle

Z,Q,S,D - Se déplacer
E,A - Tourner la caméra à 90° vers la droite/gauche
X - S'accrocher/Se décrocher avec le grappin
C - Raccourcir la corde
ESC - Menu pause
SPACE - Sauter
